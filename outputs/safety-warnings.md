# Safety Warnings

- Instagram can still flag automated behavior even when delays are conservative.
- Stop immediately if you see a warning, challenge, login prompt, or action-block page.
- Keep the daily unfollow limit low.
- Use dry-run mode before a real run.
- Keep the browser profile local and private.
- Do not run the tool from a shared account or remote environment.
- Review the CSV log and screenshots after every run.
